# 로그인 기능 정의서

## 기능 개요

사용자는 이메일과 비밀번호 혹은 google의 간편로그인으로 로그인 가능

---

## 기능 요구사항

### 로그인 기능

- 폼 형태의 로그인 페이지
- 눈 모양 아이콘 누르면 패스워드 가시화 가능
- 로그인 상태 유지
- google 간편로그인 버튼
- 아이디 찾기
- 비밀번호 찾기
- 패스워드 혹은 아이디 틀릴 시 안내문구 : 아이디 또는 비밀번호가 올바르지 않습니다. 입력한 정보를 다시 확인해 주세요. 빨간색
- x 표 클릭 시 한번에 지우기
- 탭 시 포커스 순서 input(아이디) > 인풋 패스워드 > 로그인 > x 버튼 아이디 > x버튼 패스워드 > 가시화
