# Layout Pattern

[← index](./index.md)

| 패턴             | 사용 목적                             | 구조 / 특징                                              |
| ---------------- | ------------------------------------- | -------------------------------------------------------- |
| Hero Landing     | 브랜드 소개, 제품 홍보, 서비스 시작   | Hero → Problem → Solution → Feature → Social Proof → CTA |
| Bento Grid       | 기능 소개, Dashboard, Portfolio       | 카드 단위 정보, 빠른 탐색. 긴 글·복잡한 입력 폼에는 금지 |
| Storytelling     | Brand, Exhibition, Product Experience | Visual Hero → Story → Feature Showcase → Experience      |
| Interactive Demo | SaaS, Tool, Product                   | 설명보다 체험 우선. 사용자가 직접 조작 가능해야 함       |
