# Component Design Rules

[← index](./index.md)

| 컴포넌트 | 규칙                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| Button   | Primary는 Main CTA/Submit 전용, Secondary는 Navigation/Cancel. 한 화면에서 Primary Action은 하나로 명확해야 함 |
| Card     | 정보 그룹화 목적. 모든 내용을 Card로 감싸는 방식은 금지(과사용 시 위계가 사라짐)                               |
