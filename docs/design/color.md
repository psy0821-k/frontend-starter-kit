# Color System

[← index](./index.md)

컬러는 팔레트가 아니라 **방향**으로 결정합니다. 실제 hex/oklch 값은 페이지별로 정의하되 아래 방향을 따릅니다.

| 서비스 유형 | 방향                                                   | 피할 것                         |
| ----------- | ------------------------------------------------------ | ------------------------------- |
| Trust       | 차분한 저채도, 뉴트럴 비중 높게                        | 네온 컬러, 과한 그라디언트      |
| Emotion     | 채도·대비를 높여 생동감 강조                           | 지나치게 차분한 톤(목적과 상충) |
| Content     | 뉴트럴 컬러, 배경/텍스트 대비는 낮지 않게(가독성 우선) | 배경에 강한 색 사용             |
| Data        | 상태(양호/경고/위험) 색은 의미 고정, 나머지는 뉴트럴   | 상태색을 장식용으로 재사용      |

라이트/다크 각각 별도 팔레트를 정의합니다 — 다크는 라이트를 단순히 반전한 값이 아니라 별도로 검증합니다([accessibility.md](./accessibility.md) 참조).
