# Typography Rules

[← index](./index.md)

| 유형         | 서체 방향              | 본문                              | Line Height |
| ------------ | ---------------------- | --------------------------------- | ----------- |
| Content Page | Serif + Sans 조합 가능 | 16px 이상                         | 1.6 이상    |
| Dashboard    | Sans Serif, Compact    | 14px 허용(라벨), 본문은 16px 이상 | 1.4~1.5     |

Dashboard의 정보 우선순위는 `Title → Number → Description` 순으로 배치합니다.
