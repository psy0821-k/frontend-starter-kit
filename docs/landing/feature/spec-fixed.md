# 랜딩페이지 기능 정의서 (Fixed)

원본: [spec.md](./spec.md)

이 문서는 spec.md의 기본 요구사항을 실제 개발이 가능한 수준까지
데이터 구조, UI 패턴, 엣지케이스 관점에서 구체화한 확정 스펙이다.

---

## 범위

- 이번 스코프: 랜딩페이지(카테고리별 최대 6개 섹션) + 요약 모달
- 제외: Templates 메뉴(전체 목록, 무한스크롤, 카테고리 필터) — 별도 기능 정의서로 분리
- 스타터 킷 상세 페이지(`/templates/[id]`)의 실제 UI 구현 — 이번 스코프는 라우트만 확보

## 데이터 구조

### 소스

- 정적 mock 데이터로 시작한다. `shared 계층의 api` 함수(`getStarterKits()`)로 감싸,
  추후 Supabase 연동 시 내부 구현만 교체하고 호출부는 변경하지 않는다.
- Route Handler(BFF)나 외부 CMS 연동은 이번 스코프에서 다루지 않는다(YAGNI).

### 필드 및 네이밍

- 추후 Supabase 연동을 전제로, 필드명은 Supabase 테이블 컬럼(snake_case) 규칙을
  그대로 따르는 단일 `StarterKit` 타입으로 정의한다. `id`는 UUID 문자열.
- 카드에 필요한 필드와 모달에 필요한 필드를 분리하지 않고, 하나의 `StarterKit`
  타입에 모든 필드를 포함한다(데이터 페칭 1회로 카드+모달 모두 처리).
- 필드: `id`, `title`, `summary`, `category`, `tags[]`, `thumbnail_url`,
  `description`, `features[]`, `tech_stack[]`, `preview_images[]`, `updated_at`

### 카테고리

- 카테고리 목록과 노출 순서는 코드 상수로 고정 관리한다(DB 테이블화는 보류).
- 랜딩페이지는 카테고리별로 가로(세로로 나열되는) 섹션을 구성한다.
- 각 섹션은 해당 카테고리의 스타터 킷을 최신순(`updated_at` desc)으로 정렬해
  최대 6개까지만 노출한다.

## UI 패턴

### 카드

- shadcn Card 기반. 썸네일, 제목, 한 줄 설명, 카테고리, 태그, 업데이트 날짜 표시.
- 태그는 최대 3개까지 노출하고 초과분은 `+N`으로 표시한다(카드 높이 일관성 유지).
- 그리드는 모바일 1열 → 태블릿 2열 → 데스크톱 3열 반응형.
- 이미지 로드 실패 시 고정 placeholder 아이콘으로 대체한다.

### 요약 모달

- 카드 클릭 시 shadcn Dialog(모달)로 연다. 사이드 패널(Sheet)은 채택하지 않는다
  — 모바일/데스크톱 공통 컴포넌트로 처리할 수 있고 접근성(포커스 트랩, ESC,
  aria-modal)이 기본 내장되어 있어 구현이 단순하다.
- 내용: 프로젝트 소개, 주요 기능, 사용 기술, 미리보기 이미지, 자세히 보기 버튼.
- 미리보기 이미지가 여러 장이면 좌우 네비게이션이 있는 간단한 캐러셀로 보여준다
  (1장이면 네비게이션 숨김).
- "자세히 보기" 버튼은 스타터 킷 상세 페이지 내부 라우트(`/templates/[id]`)로
  이동한다. 상세 페이지 자체 UI는 이번 스코프에 포함하지 않는다.

## 엣지케이스

| 상황                                                    | 처리                                    |
| ------------------------------------------------------- | --------------------------------------- |
| 특정 카테고리의 스타터 킷이 6개 미만                    | 있는 개수만큼만 표시                    |
| 특정 카테고리에 스타터 킷이 0개                         | 해당 섹션 자체를 숨김                   |
| 등록된 스타터 킷이 전체 0개(백엔드 장애/초기 상태 포함) | 전역 빈 상태 UI 노출                    |
| 썸네일/미리보기 이미지 URL 깨짐                         | 고정 placeholder 이미지·아이콘으로 대체 |

## 반응형

- Desktop / Tablet / Mobile 3단계 지원(spec.md와 동일).
- 카드 그리드: 모바일 1열 / 태블릿 2열 / 데스크톱 3열.

## 접근성

- 모든 카드는 Tab으로 포커스 가능해야 한다(button 요소로 렌더링).
- Enter 또는 Space로 선택(모달 오픈) 가능해야 한다.
- 이미지에는 대체 텍스트를 제공한다.
- Tab 포커스 시 outline이 시각적으로 보여야 한다.
- 모달은 포커스 트랩, ESC 닫기, `aria-modal` 등 기본 접근성을 보장한다
  (shadcn Dialog 기본 동작 활용).

## Acceptance Criteria

spec.md의 AC-01 ~ AC-03을 유지하며, 다음을 보강한다.

### AC-04

**Given** 특정 카테고리에 등록된 스타터 킷이 6개를 초과한다.
**When** 사용자가 랜딩페이지에 접속한다.
**Then** 해당 카테고리 섹션에는 최신순 상위 6개만 표시된다.

### AC-05

**Given** 등록된 스타터 킷이 하나도 없다.
**When** 사용자가 랜딩페이지에 접속한다.
**Then** 전역 빈 상태 UI가 표시된다.

### AC-06

**Given** 요약 모달이 열려 있다.
**When** 사용자가 "자세히 보기" 버튼을 클릭한다.
**Then** 해당 스타터 킷의 상세 페이지(`/templates/[id]`)로 이동한다.

## 비고

### MVP 포함 (변경 없음)

- 스타터 킷 목록
- 카드 UI
- 요약 정보
- 반응형
- 접근성

### 후속 스코프로 분리

- Templates 메뉴(전체 목록, 무한스크롤, 카테고리 필터 없음)
- 스타터 킷 상세 페이지 실제 UI
- Supabase 실제 연동(현재는 mock 데이터의 필드 스키마만 대비)
