# 랜딩페이지 기능 정의서

## 기능 개요

사용자는 랜딩페이지에서 제공되는 스타터 킷 목록을 확인할 수 있으며,
스타터 킷을 선택하면 핵심 정보를 빠르게 확인할 수 있다.

---

## 기능 요구사항

### 스타터 킷 목록 조회

- 사용자는 등록된 모든 스타터 킷을 확인할 수 있다.
- 각 스타터 킷은 카드(Card) 형태로 표시한다.
- 카드에는 다음 정보를 포함한다.
  - 썸네일
  - 제목
  - 한 줄 설명
  - 카테고리
  - 태그
  - 업데이트 날짜

---

### 스타터 킷 요약 정보

- 사용자가 스타터 킷 카드를 클릭하면 요약 정보를 확인할 수 있다.
- 요약 정보는 페이지 이동 없이 모달 또는 사이드 패널에서 제공한다.
- 요약 정보에는 다음 내용을 포함한다.
  - 프로젝트 소개
  - 주요 기능
  - 사용 기술
  - 미리보기 이미지
  - 자세히 보기 버튼

### 반응형

- Desktop
- Tablet
- Mobile

환경을 지원한다.

---

### 접근성

- 모든 카드는 키보드(Tab)로 접근 가능해야 한다.
- Enter 또는 Space로 선택 가능해야 한다.
- 이미지에는 대체 텍스트를 제공한다.
- tab시에 outline이 보여야한다

---

## Acceptance Criteria

### AC-01

**Given**
등록된 스타터 킷이 존재한다.

**When**
사용자가 랜딩페이지에 접속한다.

**Then**
스타터 킷 목록을 확인할 수 있다.

---

### AC-02

**Given**
스타터 킷 목록이 표시되고 있다.

**When**
사용자가 특정 스타터 킷을 클릭한다.

**Then**
요약 정보가 표시된다.

---

### AC-03

**Given**
모바일 환경이다.

**When**
랜딩페이지를 확인한다.

**Then**
레이아웃이 모바일 화면에 맞게 표시된다.
