있는 수직 슬라이스이며, 아래 순서대로 의존성을 가진다(이슈 1 → 2,3 → 4).

## 이슈 1: 랜딩페이지 기본 골격 + 텍스트 설명 섹션 + SEO 메타데이터

### 설명

`/`(루트)에 랜딩페이지 진입 컴포넌트를 만들고, 플랫폼 소개 텍스트 섹션과 `generateMetadata`
기반 SEO 메타태그(title/description/OG 이미지)를 구현한다. 이후 이슈(비디오, 캐러셀)가
이 골격 위에 섹션을 추가하는 기반이 된다. 모바일 퍼스트로 레이아웃한다.

### Acceptance Criteria

- [ ] Given 방문자가 `/`에 접속했을 때, When 페이지가 로드되면, Then 플랫폼을 소개하는
      텍스트(제목 + 설명)가 화면에 보인다.
- [ ] Given 모바일 뷰포트(예: 375px)일 때, When 랜딩페이지를 보면, Then 텍스트 섹션이
      한 컬럼으로 읽기 편하게 배치된다.
- [ ] Given 방문자가 페이지 소스를 확인할 때, When `<head>`를 보면, Then `title`,
      `description`, OG 이미지 메타태그가 존재한다.

### 의존성

없음 (최초 이슈).

## 이슈 2: 데모 비디오 섹션

### 설명

"코드 복사 → 붙여넣기" 사용 흐름을 보여주는 사전 녹화 mp4를 정적 자산으로 재생하는
섹션을 추가한다. `prefers-reduced-motion` 대응, 기본 음소거 자동재생(또는 클릭 재생),
지연 로딩(`preload="none"`/`metadata`)을 포함한다.

### Acceptance Criteria

- [ ] Given 방문자가 랜딩페이지를 스크롤할 때, When 비디오 섹션이 뷰포트에 들어오면,
      Then 데모 비디오가 재생된다(소리 없이 자동재생 또는 클릭 재생).
- [ ] Given 브라우저의 `prefers-reduced-motion: reduce` 설정이 켜져 있을 때, When
      비디오 섹션에 도달하면, Then 자동재생이 발생하지 않고 정지 상태로 노출된다.
- [ ] Given 페이지가 처음 로드될 때, When 비디오 섹션이 아직 뷰포트 밖에 있으면,
      Then 비디오 리소스가 즉시 전체 로드되지 않는다(지연 로딩 속성 적용 확인).

### 의존성

이슈 1 (같은 페이지 골격 안에 섹션 추가).

## 이슈 3: 인기 템플릿 집계 API + 캐러셀 섹션

### 설명

`bookmarks` 테이블 기준 북마크 수 상위 3개 템플릿을 조회하는 신규 함수
(`getPopularStarterKits`)를 추가하고, 왼쪽 텍스트(제목/사용 기술/카테고리/바로가기 버튼)

- 오른쪽 이미지(비율 1:1.1613)로 구성된 카드를 CSS `scroll-snap` 기반 캐러셀로 보여준다.
  바로가기 버튼은 `/templates/[id]`로 연결한다. 데이터가 3개 미만이면 있는 만큼만 표시하고,
  조회 실패 시 섹션 자체를 렌더링하지 않는다.

### Acceptance Criteria

- [ ] Given 북마크 수 상위 템플릿이 3개 이상 존재할 때, When 랜딩페이지를 로드하면,
      Then 캐러셀에 북마크 수 내림차순으로 템플릿 카드 3개가 보인다.
- [ ] Given 북마크된 템플릿이 2개뿐일 때, When 랜딩페이지를 로드하면, Then 캐러셀에
      카드 2개만 보이고 빈 자리나 에러가 표시되지 않는다.
- [ ] Given 인기 템플릿 조회가 실패(DB 에러)했을 때, When 랜딩페이지를 로드하면, Then
      캐러셀 섹션 자체가 렌더링되지 않는다(다른 섹션은 정상 표시).
- [ ] Given 캐러셀에 카드가 보일 때, When 카드의 바로가기 버튼을 클릭하면, Then 해당
      템플릿의 `/templates/[id]` 상세 페이지로 이동한다.
- [ ] Given 데스크톱 뷰포트일 때, When 카드 하나를 보면, Then 오른쪽 이미지 영역의
      가로:세로 비율이 1:1.1613이다.
- [ ] Given 캐러셀이 화면에 보일 때, When 별도 조작 없이 일정 시간이 지나면, Then
      카드가 자동으로 다음 카드로 전환되고, 수동 전환 버튼으로도 이동할 수 있다.

### 의존성

이슈 1 (같은 페이지 골격 안에 섹션 추가). 이슈 2와는 독립적으로 병행 가능.

## 이슈 4: 스크롤 등장 애니메이션 (gsap)

### 설명

`gsap` + `@gsap/react`(`useGSAP`)를 신규 설치해, 텍스트 설명·비디오·캐러셀 섹션이
스크롤 진입 시 순차적으로 등장하는 애니메이션을 적용한다. `prefers-reduced-motion`
환경에서는 애니메이션 없이 즉시 최종 상태로 표시한다.

### Acceptance Criteria

- [ ] Given 방문자가 랜딩페이지를 아래로 스크롤할 때, When 각 섹션(텍스트/비디오/캐러셀)이
      뷰포트에 진입하면, Then 해당 섹션이 등장 애니메이션과 함께 나타난다.
- [ ] Given 브라우저의 `prefers-reduced-motion: reduce` 설정이 켜져 있을 때, When
      섹션이 뷰포트에 진입하면, Then 애니메이션 없이 즉시 최종 상태로 보인다.
- [ ] Given 캐러셀 섹션에 카드가 여러 개 있을 때, When 섹션이 뷰포트에 진입하면, Then
      카드들이 스태거(순차) 등장한다.

### 의존성

이슈 1, 2, 3 완료 후 (애니메이션을 적용할 섹션들이 먼저 존재해야 함).
