# 랜딩페이지 — 초기 아이디어

## 배경

사용자가 첫 화면에서 만나는 웹 페이지. 이 페이지가 어떤 페이지인지, 어떻게 사용하는지 보여준다.

## 초기 요구사항 (원문)

- 사용자가 첫 화면에서 만나는 웹 페이지입니다.
- 이 페이지가 어떤 페이지인지 그리고 어떻게 사용하는지 간단하게 보여줄 수 있습니다.
- 웹페이지에 대한 설명은 텍스트로 보여주세요.
- 비디오를 통해 육안으로 들어가서 복사 붙여넣기 하는 모습을 간단하게 보여주고 싶습니다.
- 인기 있는 템플릿을 3개 정도 캐러셀을 통해 보여줄 것입니다. 왼쪽에는 제목/사용 기술/카테고리/바로가기 버튼, 오른쪽엔 이미지를 통해 보여줄 거에요. 1:1.1613 (황금비율)을 사용하세요, 비율이 틀렸다면 수정하세요.
- 모바일 버전은 스스로 생각하고 추가해주세요.
- 인터랙티브하게 만들 예정입니다.
