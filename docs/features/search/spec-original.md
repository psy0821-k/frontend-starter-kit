# Search Feature 기능 정의서 (초안)

## 배경

`/features`는 특정 페이지에 종속되지 않는 재사용 가능한 기능(Module) 모음이다 (`docs/routing.md` §/features).
현재 `/features`에는 실제 콘텐츠가 없으며, 이번에 첫 feature로 **검색(Search)** 을 추가한다.

참고 패턴: `/templates` — 목록 페이지(`docs/templates/spec.md`)에서 카드 클릭 시 상세 페이지(`docs/templates/detail/spec.md`)로 이동, 상세 페이지에서 데모/코드/사용기술을 보여주는 구조.

## 초기 아이디어

- `/features/search` 상세 페이지에서 검색 기능 자체를 데모로 보여준다.
- 체크박스로 두 가지 동작 방식을 전환할 수 있다:
  - **실시간(Live)**: 입력에 따라 즉시 필터링/검색 결과 반영. 쓰로틀링/디바운스 적용 방식과 간단한 설명을 함께 보여준다.
  - **링크이동(Navigate)**: 검색 submit 시 URL에 query params를 추가하고 페이지 이동. 이동 전 안내(막기 + 안내 문구)가 있다.
- 상세 페이지 구성 섹션(templates 상세 패턴 참고):
  - 데모(실시간/링크이동 토글 가능한 실제 동작)
  - 테스트
  - 코드
  - 사용기술

## 미확정 사항 (인터뷰에서 확정)

- primary user / 사용 시나리오
- "링크이동 방식에서 이동을 막고 안내한다"의 정확한 트리거 조건과 UX
- 디바운스/쓰로틀링 중 무엇을 기본값으로 할지, 지연 시간
- 검색 대상 데이터(무엇을 검색하는 데모인지)
- 기존 코드베이스에 재사용 가능한 검색/디바운스 유틸이 있는지
